My first portfolio project is a machine-learning web application that demonstrates how Python, natural language processing, and supervised machine learning can be combined into a working software application.

AI Fake News Detector

A machine-learning web application that analyzes news headlines and predicts whether they are likely to be fake or real.

Python Flask Machine Learning NLP TF-IDF Logistic Regression Scikit-learn Pandas
94.39% Test Accuracy
44,898 Total Articles
35,918 Training Articles

The model uses TF-IDF text vectorization and Logistic Regression to classify news headlines. The application is built with Flask and displays the model's prediction and confidence information.
